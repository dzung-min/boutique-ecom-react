# 🛒 Boutique - Modern E-commerce Frontend

A sleek, fast, and responsive e-commerce web application built with React and Redux Toolkit. This project focuses on a seamless user experience and clean state management.

## ✨ Key Features

- Dynamic Product Catalog: Browse products with real-time filtering and category sorting.

- Advanced Cart System: Add, remove, and adjust item quantities with instant UI updates via Redux.

- Persistent Storage: Shopping cart data is saved to localStorage so users don't lose their items on refresh.

- Responsive UI: Fully optimized for mobile, tablet, and desktop screens using pure CSS.

- Interactive Elements: Hover effects, smooth transitions, and loading skeletons for a premium feel.

## 🛠️ Tech Stack

- Library: React.js

- State Management: Redux Toolkit (Slices, Store, and Thunks)

- Styling: Vanilla CSS (CSS Module, Flexbox, and Grid)

- Routing: React Router DOM

- Icons: Material Icons

## 🏗️ Architecture & Logic

In this project, I prioritized clean code and a scalable folder structure:

- Redux Toolkit: Used to manage global states like cartItems, userAuth, and productData. This ensures a single source of truth across the entire app.

- Vanilla CSS: I chose not to use UI frameworks to demonstrate my understanding of CSS layouts, animations, and the box model.

- Component-Based: Reusable components to keep the code DRY.

## 🚀 Getting Started

### Prerequisites

`Node.js (v14.0 or higher)`

### Installation

Clone the repo

```
git clone https://github.com/dzung-min/boutique-ecom-react.git
cd boutique-ecom-react
```

Install NPM packages

```
npm install
```

Start the development server

```
npm start
```
